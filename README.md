# Projeto de Banco de Dados

**Nome do projeto** : Projeto Catálogo de filmes
**Equipe de Desenvolvimento**: Felipe

## 1.Visão Geral do Sistema(Escopo)
O sistema deseje permitir que o usuário organize sua coleção pessoal filmes de forma simples e visual e segura, e podera editar as informações 

## 2.Requisito Funcional(RF)
**RF01**: O sistema deve gerenciar o cadastro de seus usuários, as informações levantadas são:

 - usuário
 - senha
 
**RF02**: O sistema deve permitir que o usuario possa cadastrar filmes novos, as informações levantadas são:
 - Nome do filme
 - Ano de lançamento
 - Gênero
 - Nota de 0 a 10
 - subir imagem da capa do filme

**RF03**:O sistema deve permitir que o usuário possa editar suas informações de um filme já cadastrado, as informações levantadas são:

 - Nome
 - Ano
 - Gênero
 - Nota
 - Capa do filme
 - Excluir filme

## Requisitos não funcionais (RNF)
**RNF01**: O sistema deve ser seguro e pedir login e senha para que somente o usuário consiga acessar e mexer na sua coleção de filmes.

**RNF02**: O sistema deve ser simples e fácil de entender, para que o usuário consiga cadastrar, editar, visualizar e excluir filmes sem dificuldade.

**RNF03** :O sistema deve funcionar de forma rápida, principalmente na hora de abrir a coleção, cadastrar um filme ou editar alguma informação.

**RNF04**:O sistema deve ter uma aparência organizada e agradável, mostrando as capas dos filmes de uma forma parecida com uma estante ou galeria.
